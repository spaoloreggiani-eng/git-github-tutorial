Cos'è il Cloning?

Git Clone

Clonare significa scaricare una copia completa di un repository GitHub sul tuo computer, inclusa tutta la storia dei commit.

Lavoro Locale

Una volta clonato, puoi modificare il codice, testarlo localmente e poi sincronizzare le modifiche con GitHub.

Collaborazione

Il cloning è il primo passo per collaborare su progetti open source o lavorare su progetti di team.

Prerequisiti

1

Git Installato

Assicurati di avere Git installato sul tuo computer.

git --version

Se non è installato, scaricalo da git-scm.com

2

URL del Repository

Avrai bisogno dell'URL del repository GitHub da clonare.

Per questo progetto tutorial, l'URL sarà simile a:

https://github.com/USERNAME/git-github-tutorial.git

Sostituisci USERNAME con l'username di chi ha pubblicato il progetto.

Clonare il Repository da GitHub

1

Trovare l'URL del Repository

Vai sulla pagina GitHub del progetto che vuoi clonare.

  • Apri il repository su GitHub
  • Clicca sul pulsante verde "Code"
  • Copia l'URL HTTPS (es: https://github.com/username/git-github-tutorial.git)

Nota: Puoi anche usare SSH se hai configurato le chiavi SSH.

2

Scegliere la Cartella di Destinazione

Apri il terminale e naviga nella cartella dove vuoi salvare il progetto.

cd ~/Documenti/Progetti

Oppure su Windows:

cd C:\Users\TuoNome\Documenti\Progetti
3

Clonare il Repository

Usa il comando git clone seguito dall'URL del repository.

git clone https://github.com/USERNAME/git-github-tutorial.git

Importante: Sostituisci USERNAME con l'username GitHub effettivo!

Git creerà una nuova cartella chiamata git-github-tutorial con tutti i file del progetto.

4

Verificare il Clone

Controlla che il repository sia stato clonato correttamente.

ls -la git-github-tutorial

Su Windows usa:

dir git-github-tutorial

Dovresti vedere tutti i file del progetto: index.html, clone.html, styles.css, script.js, README.md

5

Navigare nella Cartella del Progetto

Entra nella cartella del progetto clonato.

cd git-github-tutorial

Ora sei nella cartella del progetto e puoi iniziare a lavorarci!

Aprire il Progetto in Locale

1

Aprire il Sito nel Browser

Questo è un sito HTML statico, quindi non richiede installazioni!

Puoi aprirlo in due modi:

  • Metodo 1: Fai doppio clic sul file index.html
  • Metodo 2: Trascina il file index.html nel browser

Congratulazioni! 🎉 Hai clonato e aperto con successo il progetto in locale!

2

Esplorare il Codice

Ora puoi esplorare e modificare il codice del progetto:

  • index.html - Pagina principale
  • clone.html - Questa pagina
  • styles.css - Stili CSS
  • script.js - JavaScript interattivo
  • README.md - Documentazione del progetto

Apri i file con il tuo editor preferito (VS Code, Notepad++, ecc.)

Informazioni Git del Repository Clonato

Comandi Utili

git remote -v

Mostra l'URL del repository remoto

git remote -v

git status

Verifica lo stato dei file

git status

git log

Visualizza la storia dei commit

git log --oneline

git pull

Scarica gli aggiornamenti da GitHub

git pull origin main

Modificare e Sincronizzare

Se hai i permessi, puoi modificare il progetto e inviare le modifiche a GitHub

1. Modifica

Modifica i file del progetto

>

2. git add

Aggiungi le modifiche

>

3. git commit

Salva le modifiche

>

4. git push

Invia a GitHub

!

Nota sui Permessi

Se hai clonato il repository di qualcun altro, non avrai i permessi di push.

Per contribuire a progetti altrui:

  • Fork il repository sul tuo account GitHub
  • Clona il tuo fork
  • Fai le modifiche e push sul tuo fork
  • Crea una Pull Request per proporre le modifiche

Risoluzione Problemi

Errore: Git non trovato

Installa Git da git-scm.com e riavvia il terminale.

Repository non trovato

Verifica che l'URL del repository sia corretto e che il repository sia pubblico.

File non si aprono

Assicurati di aprire index.html con un browser web moderno (Chrome, Firefox, Edge).
