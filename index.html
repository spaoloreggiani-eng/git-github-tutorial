Introduzione a Git e GitHub

Cos'è Git?

Git è un sistema di controllo versione distribuito che ti permette di tracciare le modifiche nel tuo codice nel tempo. Useremo Git per versionare questo progetto.

Cos'è GitHub?

GitHub è una piattaforma web che ospita repository Git. Pubblicheremo questo sito tutorial su GitHub per condividerlo con altri.

Il Nostro Progetto

Questo sito tutorial è un progetto HTML, CSS e JavaScript. Seguendo questa guida, creerai un repository Git e lo pubblicherai su GitHub.

Creare un Repository Git per Questo Progetto

1

Installare Git

Prima di tutto, assicurati di avere Git installato sul tuo computer.

git --version

Se Git non è installato, scaricalo da git-scm.com

2

Configurare Git

Configura il tuo nome utente e email per i commit (se non l'hai già fatto).

git config --global user.name "Il Tuo Nome"
git config --global user.email "tua.email@example.com"

Verifica la configurazione:

git config --list
3

Navigare nella Cartella del Progetto

Apri il terminale e naviga nella cartella di questo progetto (git-tutorial-standalone).

cd git-tutorial-standalone

Oppure usa il percorso completo dove hai salvato il progetto.

4

Inizializzare il Repository

Inizializza un nuovo repository Git nella cartella del progetto.

git init

Vedrai un messaggio: "Initialized empty Git repository in..."

Questo crea una cartella nascosta .git che contiene tutta la storia del progetto.

5

Verificare lo Stato

Prima di aggiungere i file, verifica quali file sono presenti nel progetto.

git status

Vedrai tutti i file del progetto: index.html, clone.html, styles.css, script.js, README.md

6

Aggiungere Tutti i File

Aggiungi tutti i file del progetto all'area di staging.

git add .

Il punto . significa "tutti i file nella cartella corrente".

7

Fare il Primo Commit

Crea il tuo primo commit con un messaggio descrittivo.

git commit -m "Primo commit: progetto Git & GitHub tutorial"

Ora tutti i file sono salvati nella storia di Git! Puoi verificare con:

git log --oneline

Configurare GitHub

1

Creare un Account GitHub

Se non hai un account, registrati su github.com

  • Vai su github.com
  • Clicca su "Sign up"
  • Compila il modulo di registrazione
  • Verifica la tua email
2

Creare un Nuovo Repository

Crea un nuovo repository su GitHub per questo progetto.

  • Accedi al tuo account GitHub
  • Clicca sul pulsante "+" in alto a destra
  • Seleziona "New repository"
  • Nome repository: git-github-tutorial
  • Descrizione: "Sito tutorial per imparare Git e GitHub"
  • Scegli Pubblico per condividerlo
  • NON inizializzare con README (lo abbiamo già)
  • Clicca su "Create repository"

GitHub ti mostrerà le istruzioni per collegare il repository locale.

3

Configurare SSH (Opzionale ma Raccomandato)

Configura una chiave SSH per connessioni sicure.

ssh-keygen -t ed25519 -C "tua.email@example.com"
# Avvia l'agent SSH
eval "$(ssh-agent -s)"
# Aggiungi la chiave
ssh-add ~/.ssh/id_ed25519

Copia la chiave pubblica e aggiungila alle tue impostazioni GitHub.

Pubblicare il Repository su GitHub

1

Aggiungere il Remote Repository

Collega il tuo repository locale a quello su GitHub. Copia l'URL dal tuo repository GitHub.

git remote add origin https://github.com/TUONOME/git-github-tutorial.git

Importante: Sostituisci TUONOME con il tuo username GitHub!

Esempio: se il tuo username è "mario", l'URL sarà:
https://github.com/mario/git-github-tutorial.git

2

Verificare il Remote

Verifica che il remote sia stato aggiunto correttamente.

git remote -v
3

Rinominare il Branch (se necessario)

GitHub usa "main" come branch principale. Rinomina il tuo branch se necessario.

git branch -M main

Questo rinomina il branch corrente in "main".

4

Push su GitHub

Invia tutti i file del progetto a GitHub.

git push -u origin main

Il flag -u imposta "origin main" come default per i futuri push.

Ti verrà chiesto di autenticarti con GitHub (username e password o token).

5

Verificare su GitHub

Apri il browser e vai su: https://github.com/TUONOME/git-github-tutorial

Dovresti vedere tutti i file del progetto:

  • 📄 README.md
  • 📄 index.html
  • 📄 clone.html
  • 📄 styles.css
  • 📄 script.js

Congratulazioni! 🎉 Hai pubblicato il tuo primo progetto su GitHub!

Aggiornare il Progetto su GitHub

Quando modifichi i file del progetto, segui questi passaggi per aggiornare GitHub

Modifica File

Apporta le modifiche necessarie ai tuoi file

>

git add

Aggiungi le modifiche all'area di staging

>

git commit

Salva le modifiche con un messaggio descrittivo

>

git push

Invia le modifiche a GitHub

Comandi Utili

git status

Mostra lo stato dei file modificati

git status

git log

Mostra la storia dei commit

git log --oneline

git pull

Scarica le modifiche da GitHub

git pull origin main

git branch

Gestisci i branch del progetto

git branch
git checkout -b nuovo-branch
